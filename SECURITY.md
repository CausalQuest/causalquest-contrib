# Security

If you find a security problem in CausalQuest, the CausalScribe sandbox, the kit or the agent API, please tell us privately.
**Do not open a public issue.**

Email **contact@causalhub.ai** with "Security" in the subject line, and include:

- what you found and where;
- the steps to reproduce it;
- what an attacker could do with it.

We will reply within three working days and keep you told of progress. Please give us a reasonable time to fix the problem before
you discuss it publicly, and do not access other players' data, disrupt the game or run automated attacks against it while you
investigate.

A community feature or mode found to be a security risk is removed for security at once. The rules are in
[`kit/CONTRIBUTING.md`](kit/CONTRIBUTING.md).
